# SQL for QA Engineers

## Overview

This repository contains SQL practice and database validation
scenarios designed for QA Automation and SDET engineers.

The project focuses on both SQL interview preparation and
real-world QA database testing.

## Skills Covered

- SQL fundamentals
- SELECT and filtering
- Aggregate functions
- GROUP BY and HAVING
- Joins
- Subqueries
- Correlated subqueries
- CTEs
- Window functions
- ROW_NUMBER
- RANK
- DENSE_RANK
- LAG
- LEAD
- Data validation
- Transaction validation
- Database integrity validation

## QA Scenarios

The repository includes examples for:

- API to database validation
- Payment validation
- Order validation
- Duplicate transaction detection
- Missing record detection
- Data integrity validation

## Interview Preparation

The repository also contains SQL solutions for common
Senior QA / SDET interview problems.
